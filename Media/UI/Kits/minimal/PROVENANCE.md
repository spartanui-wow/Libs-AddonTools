# Minimal trim kit provenance

All PNG files in this folder are deterministic Pillow output from `tools/generate_setup_assets.py`. No generated-image model or third-party artwork is used.

Exact production prompt for the set:

> Draw a neutral, faction-free window trim kit from simple one-pixel lines and flat charcoal surfaces. Include a window 9-slice, title plate, divider, primary and secondary button 3-slices, active marker, check, inset well, low-contrast material tile, empty corner ornament, soft shadow, switch track and knob, radio ring, check mark, and triangle. Keep every canvas power-of-two, every background transparent where the piece does not draw, and every form readable at World of Warcraft UI scale. Use no text, logo, crest, symbol, gradient, or decorative ornament.

The script is the editable source and records every size, color, line width, crop, and downsample operation.
